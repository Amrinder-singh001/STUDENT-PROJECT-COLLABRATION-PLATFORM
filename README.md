# Connect & Create

Build the initial foundation of my full-stack web application called ProjectConnect.

ProjectConnect is a Student Project Collaboration & Team Building Platform where college students can find teammates based on skills, create project ideas, apply to projects, form teams and collaborate.

For this first phase, DO NOT implement the complete application yet.

Focus only on:

Create the overall application structure.

Create a modern, professional and responsive UI.

Create the following pages:

Home/Landing Page

About Page

Login Page UI

Registration Page UI

Projects Explorer Page UI

Project Details Page UI

Student Profile Page UI

Student Dashboard UI

Create a consistent navigation bar and footer.

Create reusable UI components such as:

Navbar

Footer

Buttons

Cards

Project cards

Skill badges

Forms

Modal

Toast/notification

Use a clean modern SaaS-style design.

Make the entire interface responsive for:

Desktop

Laptop

Tablet

Mobile

Use semantic HTML and accessible form labels.

Use CSS Flexbox/Grid and responsive layouts.

Add realistic sample/mock project data only for UI development.

Important:

Do not implement authentication yet.

Do not implement the database yet.

Do not implement project applications yet.

Do not implement admin functionality yet.

Do not remove or rewrite existing functionality in future phases.

Keep the code modular and maintainable.

The main visual identity should communicate:

"Find Your Team. Build Something Great."

Make the interface look like a real production-quality student platform, not a basic college assignment.
